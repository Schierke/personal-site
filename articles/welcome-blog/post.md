## Technologies Used

### Go

Go is a powerful programming language that I used to build the backend of my blog. Its simplicity, performance, and strong standard library make it a great choice for web development.

### htmx

htmx is a lightweight JavaScript library that allows you to create dynamic web applications without writing a lot of JavaScript code. It simplifies the process of updating parts of a web page without reloading the entire page.

### Air

Air is a fast and customizable web server for Go. It provides hot reloading, which means that any changes you make to your code will be automatically reflected in the running server without the need to restart it.
